# 🚄 KaisatsuMod (改札Mod) for Minecraft 1.7.10

Minecraftで**リアルな駅務システム**を体験できるMODです！  
自動改札機、券売機、ICカード、運賃計算など、実在の鉄道システムをそのままゲーム内に再現しました。

---

## 🎮 このMODでできること

### 🎫 チケット・ICカードシステム
* **切符を購入**: 駅の自動券売機から目的地の切符を購入できます
* **ICカードをチャージ**: Suicaのようなカードに残高をチャージして乗車
* **運賃が自動計算**: 距離や路線に応じた運賃が自動で計算されます

### 🚪 駅の機器システム
* **自動改札機**: 切符やICカードで入退場
* **乗換改札機**: 異なる路線への乗り換えに対応
* **運賃表**: 駅間の運賃や接続情報を確認
* **係員端末**: 乗り越し精算などの手続きを実施

### 💰 経済システム
* **コインと紙幣**: 1円から10,000円まで、複数の通貨単位が利用可能
* **両替**: 小銭と紙幣を両替できます
* **RTM連携**: Real Train Modと連携すれば、より本物の鉄道体験が実現します

### 🗺️ 路線ネットワーク
* 複数の路線・駅を自由に設計可能
* 駅間の運賃を自由に設定できます
* 乗り越し精算にも対応

## 🚀 インストール方法

### 必要な環境
* **Minecraft 1.7.10**
* **Minecraft Forge 10.13.4以上** ([公式ダウンロード](https://files.minecraftforge.net/))
* **ModLoaderなど他の前提Mod**: 特に不要です（ただし互換性のためForgeのみ必須）

### インストール手順

1. **Forgeをインストール**
   - 上記のリンクからForge 1.7.10をダウンロード
   - インストーラーを実行してMinecraftに統合

2. **KaisatsuMod をダウンロード**
   - リリースページから最新版の `.jar` ファイルをダウンロード
   - `%APPDATA%/.minecraft/mods/` フォルダにコピー

3. **Minecraftを起動**
   - ランチャーでプロファイルを「Forge」に変更して起動
   - Modロードが完了すると利用可能になります

## 📖 使い方ガイド

### 基本的な流れ

1. **駅を建設**: ブロックを配置して駅務機器を設置します
2. **路線データを設定**: 駅同士を路線で連結し、運賃を設定します
3. **開始**: 自動改札機で切符を購入して乗車！

### 主なアイテム
* 🎫 **切符**: 駅の券売機で購入
* 🔷 **ICカード**: 改札機にかざして利用、チャージ機で入金
* 💎 **マジックICカード**: 残高に上限がない特殊カード
* ⚙️ **設定ツール**: 改札機などの設定用（管理者向け）

## 🆘 トラブルシューティング

**Q. Modが読み込まれない**
- Forgeが正しくインストールされているか確認してください
- Minecraftのバージョンが 1.7.10 であることを確認

**Q. 改札機が動作しない**
- 改札機が正しく設置されているか確認
- 連結された駅データが正確に設定されているか確認

**Q. 運賃表示がおかしい**
- 路線データが正しく読み込まれているか確認
- サーバーとクライアントを再起動
