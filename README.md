# Kaisatsu Mod (改札MOD)

## 概要
Kaisatsu Mod は、Minecraft内に鉄道駅の機能（改札機、券売機、ICカードなど）を追加する本格的な鉄道インフラMODです。
駅のネットワークを構築し、運賃の計算やチケットの購入、ICカードでのシームレスな自動改札の通過を可能にします。
また、**Real Train Mod (RTM)** との通貨連携機能を備えており、RTMの硬貨や紙幣をそのまま券売機やチャージ機で利用することが可能です（RTM未導入の場合は本MODの独自通貨が使用されます）。

## 追加される主な要素

### 🚂 ブロック (Blocks)
* **改札機 (Ticket Gate)**
  * ICカードや切符を使って通過できる自動改札機です。運賃が足りない場合は通れません。
* **乗り換え改札 (Transfer Gate)**
  * 異なる路線への乗り換え口に設置する改札機です。
* **券売機 (Ticket Machine)**
  * お金を入れて切符を購入するための機械です。
* **チャージ機 (Charge Machine)**
  * お金を入れてICカードに残高をチャージできます。
* **駅管理ブロック (Station Manager)**
  * 駅の名称や基本情報を設定・管理するコアブロックです。
* **路線管理ブロック (Line Manager)**
  * 各駅をつなぐ「路線」を定義し、運賃などを管理するためのブロックです。
* **駅員端末 (Staff Terminal)**
  * 駅員として各種設定や運賃・残高の調整などを行うための端末です。
* **証明書発行機 (Certificate Machine)**
  * 遅延証明書や乗車証明書などのアイテムを発行する機械です。
* **運賃表ブロック (Fare Chart)**
  * 壁に設置して駅の運賃表を掲示するためのブロックです。
* **アルミニウム鉱石 (Aluminum Ore)**
  * 地下に生成される新しい鉱石です。ICカードや機械のクラフト素材となるアルミニウムを精錬できます。

### 💳 アイテム (Items)
* **ICカード (IC Card)**
  * チャージ機でお金をチャージして、改札をワンタッチで通過できる便利なカードです。
* **魔法のICカード (Magic IC Card)**
  * 残高を気にせずどこでも改札を通過できるクリエイティブ専用の無限ICカードです。
* **切符 (Ticket)**
  * 券売機で行き先（降車駅）などを記録して発行される片道用の切符です。
* **設定ツール (Setting Tool)**
  * 駅管理ブロックや改札機などの各種設定を行うための専用ツールです。
* **証明書 (Certificate)**
  * 証明書発行機から出力されるアイテムです。
* **アルミニウムインゴット (Aluminum Ingot)**
  * アルミニウム鉱石を精錬して得られる、各種機械やアイテムの主要なクラフト素材です。

### 💰 通貨システム (Money)
本MODは独自の通貨アイテム（1円, 5円, 10円, 50円, 100円, 500円硬貨、および1000円, 2000円, 5000円, 10000円紙幣）を追加します。
作業台のクラフト機能を使って、インベントリ内で簡単に両替・逆両替が可能です（例：100円玉5枚 ⇔ 500円玉1枚）。

## 連携機能
* **Real Train Mod (RTM)連携**:
  RTMが導入されている環境では、RTMの通貨アイテム（item.rtm:money）を自動で認識し、券売機やチャージ機での支払いにそのまま使用・お釣りとして出力することが可能になります。
